# WB promotion writes

Изменения не выполняются самим планирующим инструментом.

1. Прочитать объект.
2. Создать нужный `wb_plan_*`.
3. Показать confirmation ID и безопасную summary.
4. Получить явное подтверждение пользователя.
5. Выполнить `wb_apply_change` один раз в той же живой MCP-сессии:
   confirmation хранится только в памяти процесса.
6. Перечитать объект.

Доступны планы создания/управления кампанией, ставок, минус-фраз и
пополнения бюджета. Пополнение и запуск никогда не объединяй в одну
автоматическую операцию.
