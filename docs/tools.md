# Справочник MCP-инструментов WB

Все инструменты возвращают JSON. Инструменты чтения выполняются сразу;
изменения всегда создают план и выполняются только отдельным
`wb_apply_change`.

Для точной структуры параметров вызовите `wb_describe_operation` с именем
инструмента. Почти все бизнес-инструменты получают объект `payload`; у
`wb_apply_change` и `wb_describe_operation` параметры находятся в корне.

## Чтение

## Планы изменений

План не вызывает API записи. Он возвращает `confirmation_id`, который
одноразово передаётся в `wb_apply_change`. Даже неуспешное применение не
повторяется автоматически. ID хранится только в памяти процесса: plan и apply
должны пройти через один живой экземпляр MCP.

| Инструмент | Планируемое действие |
| --- | --- |
| `wb_plan_update_cards` | Обновление карточек. |
| `wb_plan_save_media` | Полная замена медиа карточки. |
| `wb_plan_set_prices` | Цены и скидки. |
| `wb_plan_set_stocks` | Остатки на складе. |
| `wb_plan_manage_warehouse` | Создание, изменение или удаление склада. |
| `wb_plan_cancel_order` | Отмена FBS-заказа. |
| `wb_plan_create_supply` | Создание FBS-поставки. |
| `wb_plan_update_supply` | Заказы и доставка FBS-поставки. |
| `wb_plan_update_campaign` | Создание, запуск, пауза, остановка, удаление или переименование кампании. |
| `wb_plan_update_bids` | Ставки кампании в копейках. |
| `wb_plan_update_minus_phrases` | Полная установка минус-фраз; пустой список очищает их. |
| `wb_plan_start_report` | Запуск отчёта воронки продаж. |
| `wb_plan_reply_feedback` | Ответ на отзыв. |
| `wb_plan_reply_question` | Ответ на вопрос. |
| `wb_plan_send_chat_message` | Текстовое сообщение в чат. |
| `wb_plan_deposit_campaign_budget` | Явное пополнение бюджета кампании в рублях с выбранного источника. |

## Управление

| Инструмент | Назначение |
| --- | --- |
| `wb_describe_operation` | Русская подсказка, обязательные поля и безопасный пример инструмента. |
| `wb_apply_change` | Однократно применяет ранее созданный план по `confirmation_id`. |

## Безопасность

- Токен передаётся только через `WB_API_TOKEN` в окружении процесса, не через
  аргументы инструментов и не в ответы MCP.
- Сводка плана скрывает токеноподобные значения и подписанные URL.
- Не передавайте модели реальные токены, ключи или подписанные ссылки.
